Privacy Policy

killtony-clipbot · Effective date: October 13, 2026

killtony-clipbot ("the app") is a personal tool used only by its developer, with the developer's own Google account. This policy explains what Google user data the app accesses and how it is handled.

Data the app accesses

The app requests one Google permission: the YouTube upload scope (https://www.googleapis.com/auth/youtube.upload). It is used only to upload video files to the authorizing user's own YouTube channel. The app does not read, list, edit, or delete any other content in the account.

How data is used

Access is used solely to perform those uploads. The app does not use Google user data for advertising, analytics, profiling, or any other purpose.

Storage

The authorization token issued by Google is stored locally, as a file on the developer's own computer. The app has no server, and no Google user data is transmitted to or stored on any server operated by the developer.

Sharing

The app does not share, sell, or transfer Google user data to any third party.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. Deleting the locally stored token file also ends the app's access.
